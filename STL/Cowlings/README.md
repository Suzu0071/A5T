# Cowlings

Configurator options:
+ Nozzle Leds(N): brackets for mounting nozzle leds.
+ Rigid Top Mount(R): indents for longer screws on the top of the cowling.
+ Barf(B): change the logo led to a rainbow barf led.
+ Sapphire Diffusor(S): changes the logo diffuser to a 8x8mm sapphire. Note: dont print a diffuser, only the led carrier.
+ Extended Mount(E): slightly extends the cowling forward to prevent the hotend colliding with cartographer/beacon.

These options are **on** by default:

+ Nozzle Leds
+ Rigid Top Mount
+ Extended Mount

___

Note: cowlings for Vindr fans have a `-VINDR` in the name.
